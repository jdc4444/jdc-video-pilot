# JDC adaptive video pilot

Public, reversible delivery test for 29 verified homepage clips. The portfolio remains
hosted and managed in Squarespace; this repository serves only the temporary HLS
pilot assets used behind the `jdc-video-pilot=1` switch.

No source masters, local filesystem paths, build manifests, or credentials are
published here.

The one homepage clip without a verified local match remains on Squarespace's
native HLS route. Project-page video delivery also remains on Squarespace.
